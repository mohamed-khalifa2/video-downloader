# VidDownloader

VidDownloader is a full-stack web application that analyzes video URLs and extracts downloadable formats from multiple platforms.

---

## Features

- Analyze video URLs and return available formats
- Support for YouTube videos with multiple quality options
- Support for platforms such as TikTok, Facebook, and Instagram via yt-dlp
- Structured backend architecture

---

## Tech Stack

### Backend
- Node.js
- Express.js
- yt-dlp (via yt-dlp-exec)

### Frontend
- Angular
- Tailwind
